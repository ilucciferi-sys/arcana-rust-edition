# Подготовка огненных заклинаний

Подготовка следует исходной хореографии и времени каста. Дуги постепенно
собираются в печать, символы загораются по очереди, затем проявляются
авторская огненная печать и ядро из восьми кадров пламени. Текстуры
`sigil_fire`, `halo` и `flame_0..7` перенесены побайтово.

| Заклинание | Отличительный элемент подготовки |
| --- | --- |
| Искра | Компактный огонёк и одна сходящаяся искра |
| Воспламенение | Шесть направленных штрихов |
| Огненный толчок | Расширяющиеся кольца давления |
| Огненный шар | Три вращающихся потока вокруг ядра |
| Стена пламени | Вертикальные штрихи будущей преграды |
| Пламенный щит | Пересекающиеся защитные обручи |
| Кольцо огня | Восемь радиальных лучей |
| Огненный взрыв | Сходящиеся к центру огненные спицы |
| Луч Инферно | Последовательность сужающихся колец |
| Огненный шторм | Спираль, собирающаяся над ладонью |
| Удар феникса | Два веера, напоминающих раскрывающиеся перья |
| Метеоритный дождь | Четыре вращающихся фрагмента |
| Солнечное копьё | Печати дополняют существующее GPU-ядро копья |
| Воплощение Огня | Перекрещённые линии и обручи вокруг тела |

Рывок сохраняет исходное мгновенное пассивное действие. Для него не добавлена
длительная подготовка. У заклинаний высокого уровня, воздействий на землю
и превращений появляется печать под ногами. У высшей магии наблюдатель
видит ещё три печати над персонажем.

От первого лица печать и огненное ядро уменьшаются при приближении ладони
к камере. Геометрия руки вплотную к глазам обрезается, чтобы поднятый
локоть не закрывал экран; мировая поза и точка выпуска сохраняются.
Верхние печати собственного персонажа скрыты. Печати, ореол и пламя
используют существующий слой свечения; верхние круги сделаны менее яркими.

Подготовка восстанавливается по публичным событиям каста и UUID персонажа.
Её видит присоединившийся во время каста игрок. При отмене она затухает
вместе с позой, при выпуске — за четыре тика. Смерть и смена измерения
используют существующую очистку каста. Временные визуальные объекты
не сохраняются в мире и не влияют на урон, ману или время подготовки.

Качество `performance`, `high`, `cinematic` ограничивает одну подготовку
240, 480 и 640 геометрическими элементами соответственно. После 32 блоков
детализация уменьшается, после 96 — подготовка не рисуется. Режим
`ARCANA_REDUCED_EFFECTS` снижает яркость и число элементов. Эти ограничения
относятся к подготовке; они не заменяют профилирование всей сцены.

Огненное пробуждение также использует авторскую печать. При отмене ритуала
она затухает за 0,2 секунды. Конструкция и условия пробуждения сохранены.

Проверочный сценарий: `arcana/tools/validate-fire-preparation.py`. Он запускает
два скрытых клиента в отдельных профилях без звука и проверяет подготовки,
позднее подключение, отмену, смерть/возрождение и огненное пробуждение.
Подробные результаты — в [VALIDATION.md](VALIDATION.md).
